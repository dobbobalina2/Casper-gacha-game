# Casper — Gacha Game

A quick collectible game exploring gacha-style reveals and collection building.

## Direction

Build around collectible collections, potentially Pokémon or another collectible theme. The relationship to Collector Crypt is still to be confirmed.

## Proposed first playable

1. Pick a collection.
2. Open a pack using demo credits.
3. Reveal a collectible and its rarity.
4. Add it to a collection binder.
5. Track progress toward completing the set.

This is a starting proposal, not a finalized game design. Pokémon and other themes remain options.

## Status

Repository initialized with a product brief. No game implementation, live collectible integration, or deployment exists yet.

See [the product brief](docs/product-brief.md) for decisions to make before implementation and [the project wiki](docs/wiki/README.md) for the project map.
